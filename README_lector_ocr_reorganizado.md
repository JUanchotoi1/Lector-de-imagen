# Lector de Imagen — OCR

Proyecto reorganizado en tres archivos. La lógica de la aplicación se conserva.

- `lector_de_imagen_esc_ner_ocr.html`: interfaz y carga de dependencias.
- `lector_de_imagen_esc_ner_ocr.css`: estilos propios de la interfaz.
- `lector_de_imagen_esc_ner_ocr.js`: cámara, lotes, OCR, ficha y exportaciones.

Mantén los tres archivos en la misma carpeta y abre el archivo HTML.
